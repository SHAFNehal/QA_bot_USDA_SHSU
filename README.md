# LLM QA Dataset Generator, Fine-Tuner, and RAG Chatbot

This repository contains all necessary Python modules and utilities to:
1. Generate a comprehensive QA dataset from input documents using a small language model.
2. Fine-tune open-source LLMs using the generated dataset.
3. Deploy a lightweight RAG-based chatbot that can answer questions from your domain-specific documents.
